# Pocket First App

Design and build this app mobile-first: assume a phone-width screen (~375-430px) as the primary target, not desktop. Use responsive flexbox/grid layouts, touch-friendly tap targets (minimum ~44px), and ensure the folder tree sidebar and all screens scroll properly and never overflow horizontally on a narrow screen.

This project was built with [Lovable](https://lovable.dev).
